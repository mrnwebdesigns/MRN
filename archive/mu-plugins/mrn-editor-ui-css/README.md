# Archived: MRN Admin UI CSS Legacy

Retired compatibility source for `mrn-editor-ui-css`. The active `mrn-admin-ui-css` platform component supersedes this code. The archived component is not loaded, packaged, or supported for new sites.

## Reactivation

Reactivation requires an explicit compatibility decision, restoration to an active source layer, current static QA, and runtime admin-screen regression testing.
