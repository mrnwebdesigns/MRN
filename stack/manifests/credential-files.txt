# Logical credential key -> stack secret filename.
#
# This is the vendor-neutral contract between the MRN credential store and the
# stack bootstrap. Keys are logical names owned by the credential model; they
# are NOT tied to any secret provider. Swapping the upstream provider must not
# require a change to this file.
#
# Consumers:
#   - stack/manifests/licenses.txt reads the resulting files via secretfile:/secretfilejson:
#   - a materialisation step writes <stack_root>/secrets/<file> from the credential store
#
# Rules:
#   - Never store secret values here. Filenames and key names only.
#   - Multiple keys separated by commas materialise one JSON file.
#
# Format: <LOGICAL_KEY[,LOGICAL_KEY...]>|<secret filename>|<text|json>
