# Development Credential Readiness Fleet Release

Release: `2026.09.24-dev-credential-readiness-fleet`

## Scope

- Promote `mrn-stack-deployment-agent` `0.2.5` as the exact full-Stack Fleet
  prerequisite.
- Keep complete managed service credentials mandatory for production sites.
- Treat `local`, `development`, and `staging` WordPress environment types as
  non-production for this credential policy.
- Treat the canonical `*.mrndev.io` development hostname as non-production when
  an older site still reports WordPress's default `production` environment.

## Safety contract

- The readiness response reports `required`, `configured`, and `ready`
  independently. A development exemption does not claim missing credentials are
  configured.
- Plugin active-state, exact version/tree, child-theme shape, signed release
  identity, backup, atomic apply, rollback, and runtime readback gates are not
  relaxed.
- The agent package remains upgrade-only. A missing installation requires a
  separately authorized, backup-gated prerequisite plan.
- This source promotion does not itself deploy a child site.

## Verification

- Agent regression tests cover production failure, production success,
  WordPress staging, canonical MRN development hostname fallback, and derived
  child metadata.
- Agent CI passes on PHP 7.4 and PHP 8.3.
- Stack registry tests verify that `0.2.5` is the newest exact forward release.
- Final candidate QA, deterministic full-Stack package generation, per-site
  preflight, backup, authorization, apply, and readback remain distinct gates.
