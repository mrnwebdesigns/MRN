# After Content field preparation

Parent theme 1.5.4 makes the keyed After Content field callback honor the
existing builder editor-contract predicate. Anonymous value reads still clone,
finalize and register the complete layout tree, including nested fields and
retained legacy layouts. Only the subsequent editor-control reconstruction is
skipped on public requests. Admin and AJAX requests keep that reconstruction;
frontend or REST editing integrations retain the existing explicit opt-in.

This fixes a bypass of the request guard already used by the general
flexible-content callback. It does not change ACF registration, stored content,
template markup, form validation, cache configuration or third-party scripts.

## Qualification

The focused regression exercises both keyed load/prepare hooks, public values,
hidden fields, nested AJAX-backed selectors, retained legacy layouts, validator
defaults, admin/AJAX editor controls and explicit integration opt-in/opt-out.
The complete parent-theme PHP harness, syntax and risk scan pass. The separate
MRN staged-tree QA report is required before committing this change.

A process-local, read-only CLI comparison against the Gloves runtime on
2026-10-06 preserved the homepage's saved After Content values and all 1,206
keyed runtime layout definitions. Explicit editor preparation matched the
original editor field tree. The first measured pair reduced this callback from
173.345 ms to 14.592 ms. These are separate CLI requests with CLI OPcache off;
they are not PHP-FPM timings, visitor distributions or a PageSpeed improvement.

The source function was loaded only into the disposable diagnostic processes.
No installed parent-theme file, setting, content or log was changed. This does
not establish browser/editor qualification of an installed release.

## Rollout boundary

The intended targets are Gloves Dev (`https://gloves.mrndev.io`) followed by
Gloves Live (`https://gloves-online.com`). Do not run speed tests on Dev. Each
write needs an exact merged parent artifact, active child/template identity,
fresh verified remote database-only backup, retained rollback, checksum
readback, functional/browser/API checks and fresh-log inspection. Live needs
new public performance measurements before claiming a score improvement.

At preparation time the canonical MainWP release route exposes full-Stack
deployment, while the separate parent-theme-only deployment task still has
uncommitted transport work. Do not deploy that unfinished tool, substitute a
manual file copy or broaden this fix into a full-Stack rollout. Source
acceptance and the qualified Dev/Live rollout remain separate gates.

The installed Gloves parent was 1.5.2. Canonical 1.5.3 adds only version and
formatting changes within the parent tree. The release must still reconcile
the exact parent diff and artifact at packaging time. No full-Stack release
lock or Fleet baseline is promoted by this feature commit.
