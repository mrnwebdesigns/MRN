## Corrections during integration

The inactive quotation/tag branches initially emitted additional whitespace.
They now preserve the existing unconfigured Body Text output exactly. The
native SEO regression retains exact public-main HTML and stored-data hashes.

An empty labeled-logo row accessed an unset description, and an image-only
labeled item could access an unset label. Both optional values now use a
null-aware check. Native regressions elevate those warnings to failures and
retain the release fixture's independent zero-diagnostics gate.

The new automatic presentation suite covers native ACF persistence, malformed
values, dormant controls, conditional assets, keyboard access, responsive and
reduced-motion behavior, whole-page WCAG A/AA, JavaScript-free disclosures and
Classic Editor save/reload. It also exercises six existing Text Swipe panels:
the fixture represents a legacy collection through its own synthetic WordPress
metadata; the five-item policy for new collections is not relaxed. Standard
MRN runtime/API/performance QA includes the presentation page.

The first cumulative candidate, `2026.10.26-fleet-auto-53d984d850bb`, was
correctly blocked by the added public readback after an editor save. PHP's
default 1,000-input limit truncated the large native form and dropped its last
sections. Parent 1.6.11 places integrity markers before and after supported
Classic Editor forms and rejects an incomplete submission before WordPress
writes. Native authorization, autosave, REST and WP-CLI behavior are unchanged.
The browser regression rejects a missing-tail request, then verifies a complete
save preserves all six Text Swipe panels and the other presentation controls.

The large positive qualification fixture explicitly uses 10,000 input capacity;
this does not change any site's PHP configuration. A separate negative fixture
uses the actual 1,000-input limit, records the expected PHP startup truncation
warning and proves the post title, content and all saved metadata are unchanged.
That deliberately overflowing request is separate from the required clean
positive runtime. Site QA should verify native editor saves at the site's real
PHP input capacity before rollout.

Direct mobile visual readback also found that a framed image with authored text
could retain WordPress's 1,500-pixel auto-sizes fallback height after lazy loading.
The existing attachment-ratio protection had only covered image-only frames.
Parent 1.6.12 applies that same native ratio to standard/drift frames with text,
while preserving ordinary unframed markup and explicit crop stages. Qualification
now measures the loaded image's geometry at every viewport/motion combination.
The unpublished `2026.10.26-fleet-auto-c3fb3aad731f` candidate was held for this
correction; its evidence and immutable lock remain preserved. Mobile gutter and
tab density remain part of later site-specific visual QA using actual site styles.

Historical migration receipts are retained privately as provenance, not reused
as current release approval. In particular, their old contrast exception does
not apply to the new whole-page accessibility checks. Current task evidence is
under `MRN-release-artifacts/2026-10-26-baseline-consolidation/`.
