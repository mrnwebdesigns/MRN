# AME menu visibility release

Release: `2026.10.02-ame-menu-visibility`.

## Change

Public Security Hardening `0.4.3` respects the final menu produced by Admin
Menu Editor. Previously, the shared MU component restored Advanced/Public
Security after AME had removed it for Shop Manager. The reassertion callback
now returns once AME has completed its menu replacement. The native fallback
without AME and existing capability checks remain unchanged.

No new menu, role capability, database migration, or child-theme workaround
is included. The existing standalone Broken Links entry remains available.
