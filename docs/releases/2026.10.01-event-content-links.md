# Event links in Content Only mode

Parent theme 1.5.1 connects the existing Event Image Link ACF field to Reference
Content destinations. Events opt into the same supported-destination contract as
Resources, so Content Only mode no longer disables the row's Enable Item Links
control. Images, titles and read-more links use the saved URL. New-tab links
preserve the saved preference and include noopener.

The row's explicit link-off preference takes precedence. Content Only Events
without a valid saved destination remain unlinked. Public Events without a saved
destination retain their public permalink. The field key and stored data are
unchanged; no content migration or new plugin is required for the shared repair.
Headers, footers, breadcrumbs, layouts and CSS declarations are unchanged.
