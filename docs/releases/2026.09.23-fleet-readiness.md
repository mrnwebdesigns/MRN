# 2026.09.23 Fleet Readiness

This release reconciles the clean merged Stack baseline with its package and
control-plane contracts. It does not deploy a child site.

## Included reconciliation

- Preserve the required Tokens `0.1.4` baseline and all prior Stack runtime
  fixes.
- Record MRN Hierarchical Menu Taxonomies `0.1.1`, whose stable main-file
  compatibility bootstrap prevents package replacement from orphaning the
  WordPress activation key.
- Make release ZIP generation resolve canonical standalone-plugin sources from
  dedicated Git worktrees, including repositories whose WordPress plugin lives
  below the repository root.
- Rebuild and checksum the current bootstrap packages and parent/child theme
  archives from clean merged source before syncing the Stack package store.
- Preserve optional-plugin upgrade-only behavior. Registration or package
  availability does not authorize installation when a plugin is absent.

## Qualification contract

- Full Stack deployment remains site-by-site, backup-gated, checksum-locked,
  child-theme-preserving, and subject to exact inventory/preflight readback.
- Independent optional-plugin candidates retain their own canary and rollout
  gates; this release does not silently promote or install an unfinished
  optional-plugin branch.
- MainWP Operations API remains a Dashboard-only component and must match the
  version required by the Stack catalog before Fleet writes are attempted.
