# 2026.09.23 Mobile Navigation Fleet

This release promotes the completed parent-theme mobile-navigation first-paint
repair on top of the full `2026.09.23-fleet-readiness` baseline. It does not
deploy a child site.

## Included change

- Advance `mrn-base-stack` from `1.4.1` to `1.4.2`.
- Select mobile/tablet drawer mode while the header is parsed, before the
  expanded no-JavaScript fallback can paint in normal document flow.
- Attach the small critical controller to the existing WordPress script handle
  as inline JavaScript, avoiding a new blocking request.
- Enable drawer transitions only after the visitor first opens the menu.
- Preserve child-owned headers, configured breakpoint boundaries, submenus,
  keyboard/focus behavior, resize behavior and the JavaScript-disabled fallback.

The focused suite covers 390, 900, 901 and 1366 pixel widths, streaming first
paint, drawer interaction, submenu links, focus containment, Escape, resizing,
no-JavaScript behavior, delayed/footer placement, transition suppression,
incomplete markup fallback and WCAG A/AA checks.

## Independent candidates reconciled but not promoted

- Cookie Consent 1.1.46 source is merged in its standalone repository and exact
  1.1.43, 1.1.45 and 1.1.46 artifacts are retained. Its optional Fleet record
  remains on 1.1.43 until the separately confirmed, backup-gated 1.1.46
  Tharrington Smith canary passes.
- The stale Cookie Consent 1.1.45 metadata PR is closed as superseded; its exact
  artifact remains available for the current canary and rollback.
- The reCAPTCHA async-v3 experiment is closed without promotion because its
  production trial was rolled back and did not establish a sustained mobile
  performance improvement.

## Rollout contract

- Full Stack updates remain site-by-site, checksum-locked, backup-gated and
  child-theme preserving.
- Resolve the active `stylesheet` and `template` before changing a theme.
- Require exact inventory, preflight, current release-lock identity, rollback
  material, cache purge and public/runtime verification for every site.
- Optional-plugin registration remains upgrade-only and never authorizes an
  installation where the plugin is absent.
