# Stack and Fleet reconciliation, October 7

## Scope and failure

The source audit covers September 23 through October 7, the current Stack
default branch, every unmerged Stack task branch and all 37 standalone plugin
repositories. It compares the current platform lock and the October 5 bootstrap
plugin inputs with fresh origin references. Site content and child presentation
remain site-owned. This is source/package reconciliation with Trilliant local
qualification, not authorization for a Dev or production deployment.

Trilliant Dev selected parent 1.5.1.2 from the shared Stack backport at
`c6ee037ed114a3644bf85dc9a6e71169c2f9f983`. That parent included Text Swipe.
The local cumulative update replaced it with published parent 1.5.3 from
`2026.10.05-stack-bootstrap-r1`, which did not include that feature. The saved
`text-swipe` value remained intact, but the renderer's older allow-list converted
it to `instant`. A matching release lock alone did not establish feature parity.

## Reconciled inputs

The forward feature commits `960b390` and `07e1fab` are integrated from PR #195,
including the ACF choices, PHP registry-based renderer, JavaScript, CSS and
browser/PHP regressions. Parent 1.5.5 is based on current merged source and
preserves the Events links, nested ACF validator defaults, mobile navigation,
asset loading and other existing contracts. The old 1.5.1 backport is recovery
history rather than a second source input. Version 1.5.4 is reserved by the
separate After Content draft and its behavior is not implied by 1.5.5.

The local updater at `c58854f` is also integrated into the shared source. It
remains a code-only, checksum-bound adapter with retained rollback. It changes
neither remote deployment authorization nor existing-site retirement policy.
