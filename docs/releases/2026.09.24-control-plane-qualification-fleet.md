# Control-Plane Qualification Fleet Release

Release: `2026.09.24-control-plane-qualification-fleet`

## Scope

- Advance the Dashboard-only MainWP Operations API contract to `0.9.7`.
- Apply the Deployment Agent `0.2.5` production credential requirement
  consistently in release-independent qualification and exact release
  preflight.
- Require controller `0.9.7` in current optional-plugin Fleet plans.
- Preserve every child-site component version and runtime tree from
  `2026.09.24-dev-credential-readiness-fleet`.

## Safety contract

- Production sites still require complete managed credentials.
- Recognized development sites may qualify when credentials are not configured
  only when the authenticated agent explicitly reports that they are not
  required.
- Older agents that omit the requirement remain fail-closed.
- The controller remains Dashboard-only and is never included in a child-site
  package.
- Exact-site resolution, current inventory, backup, confirmation, active-state,
  checksum, child-theme preservation, rollback, and runtime readback gates are
  unchanged.

## Verification

- Controller regression tests cover required, non-required, and legacy
  missing-requirement credential states on PHP 7.4 and PHP 8.3.
- The `0.9.7` Dashboard deployment followed a verified remote database-only
  Updraft backup.
- Dashboard readback reports the plugin active at `0.9.7`, and all eight
  deployed runtime files match the immutable release artifact.
- MainWP exposes 84 abilities, including the complete 22-ability MRN control
  plane.
- Gloves Online remains production-credential-ready; Trilliant development and
  Doster development qualify with `required=false`, `configured=false`, and
  `ready=true`.
- This release preparation does not deploy the full Stack to a child site.
