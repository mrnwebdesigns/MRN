## State Contract

- The child loader remains authoritative for raw component and drift evidence.
- MainWP records an approved overlay only after a backup-gated write passes
  exact inventory, version, tree checksum, file count, loaded-state, and
  active-state readback.
- A fresh runtime report labels the site `current_with_approved_overlays` only
  when every raw drifted component matches its site, immutable baseline, plan,
  package checksum, tree checksum, version, and file count in the Dashboard
  ledger.
- An unrecorded component, changed artifact, changed baseline, missing required
  component, or legacy collision remains `drifted`. Raw `drifted_required`
  evidence is never removed or rewritten.
- A baseline-restoring selective rollback removes that component record. An
  exact full-Stack deployment clears all records for that site only after the
  new immutable runtime is verified.
