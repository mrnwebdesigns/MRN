# SendGrid Optional Fleet Release

Release: `2026.09.24-sendgrid-optional-fleet`

## Scope

- Retain `mrn-sendgrid-provisioning` as a supported, catalog-only optional
  integration.
- Remove the plugin from the standard bootstrap manifest, generated full Stack
  release lock, Fleet package, and required standalone-source drift audit.
- Default management-key delivery and automatic SendGrid provisioning to off.

## Safety contract

- A full Stack release never installs SendGrid Provisioning on an absent site.
- A full Stack release never removes, deactivates, overwrites, or reconfigures
  an existing SendGrid Provisioning installation.
- SendGrid provisioning requires a separately approved plugin installation and
  an explicit `STACK_BOOTSTRAP_SENDGRID_AUTO_PROVISION=1` bootstrap opt-in.
- The high-privilege SendGrid management key is not read from the Stack secret
  file or written into WordPress unless that opt-in is enabled.
- MRN Tokens `0.1.4` remains platform-required. Missing sites must receive its
  separately authorized, backup-gated install-and-activate prerequisite before
  a full Stack deployment.

## Verification

- Archive and checksum the prior immutable release lock without modification.
- Run the Stack test suite, JSON and shell validation, task-scoped MRN QA, and
  the staged commit gate before merging the metadata change.
- Generate the new release lock only from clean merged `main`, commit it
  separately, and run promotion audit/candidate and full release QA.
- Build exact-site Fleet plans and verify that SendGrid Provisioning is absent
  from every plan while MRN Tokens remains required.
- Any authorized Tokens prerequisite installation requires a fresh verified
  remote database-only backup and installed-version, active-state, checksum,
  and exact-site preflight readback.

This release preparation does not remove SendGrid from any site and does not
authorize a full Stack deployment.
