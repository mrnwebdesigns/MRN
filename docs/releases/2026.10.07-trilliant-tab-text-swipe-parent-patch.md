# Trilliant Dev parent-only tab animation qualification

## Result and scope

On 2026-10-07, the owner-authorized parent-only transaction deployed
`mrn-base-stack` **1.5.1.2** to
<https://trilliant.mrndev.io/partner-ecosystem/>. The six Image Content panels
retain their original CTA presentation. The existing Tab Animation field is
`text-swipe` (Text Swipe + Edge Fade); only heading/body text moves, with a
temporary edge mask. Instant, Fade, Slide, and reduced-motion behavior remain

site-owner operator adapter uses MainWP target/sync/backup evidence and a
private, immutable parent selection. It does not add a Dashboard ability or
update the installed deployment agent.
