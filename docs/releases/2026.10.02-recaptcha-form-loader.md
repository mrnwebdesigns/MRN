# reCAPTCHA Manager 0.1.4 optional release

Adds a default-off, form-aware WPForms classic-v3 loader. Sites opt in through
`mrn_recaptcha_form_aware_loading`; only a single protected form and WPForms
2.0.1.1 or 2.0.2.1 qualify. Unknown integrations retain native loading. The Google
API loads near the form or on interaction; every valid submit obtains a fresh
token before native submission. Errors restore the button and expose a retry
message. Server validation, keys and thresholds are unchanged. Later loading
provides Google less pre-interaction context; fraud-scoring equivalence is not
claimed.
