# Prioritized UX refinement backlog

## P1 — before release consideration

- Qualify Local Hub VM stability after the recorded guest-agent OOM interruption. The demo has recovered, but the exact allocation cause is unconfirmed. Avoid parallel heavy fixture workloads until that is resolved.

- Have an MRN editor review the integrated dashboard → list → editor → settings workflow. Record completion time, errors and confidence against the native baseline. Targets remain measurement targets, not absolute acceptance thresholds.
- Extend WebKit from the passing settled-navigation smoke to native write workflows before release consideration. Preserve WordPress nonce, authentication and ACF protections; do not suppress request errors.
- Retain the native save/reload, incomplete-save, accessibility and performance checks as blockers for future changes. The local results do not qualify other site themes, browser versions or plugin configurations.

## P2 — subsequent polish pass

- Review content list column density with real SEO metadata and Screen Options. Keep third-party SEO columns/controls owned by their providers.
- Refine individual dense ACF sections: guidance, labels and tab hierarchy. Preserve the approved one-section workspace and original field tree.
- Review section selection after insert/remove and cross-region arrangement with more editorial tasks; keyboard moves currently stay within the owning native ACF region.
- Refine dashboard priorities and empty analytics/form-widget states through their existing owners. Do not rebuild those apps inside MRN.
- Audit native ACF/TinyMCE accessibility findings with the provider/version baseline. The new MRN surface scans do not certify the entire editor.
- Evaluate concise dirty/unsaved-state feedback with the existing native publishing toolbar before adding another state system.

## P3 — optional refinements

- Adjust spacing and metadata density after the integrated editor review.
- Consider deeper summary/search content only when editors identify a missed find task; avoid indexing every rich-text field on each keystroke.
- Reconsider cross-document animation only after native rich-text navigation is independently stable; ordinary navigation is intentional in this pilot.

No backlog item authorizes release preparation, deployment, Fleet work or a new implementation sprint.
