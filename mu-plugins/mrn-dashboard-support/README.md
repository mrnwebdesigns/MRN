# MRN Dashboard Support

Standalone plugin migrated from mu-plugins. Provides the support widget and the admin-only Notifications Center.

## Version
- 1.3.1

## Files
- `mrn-dashboard-support.php`
- `mrn-logo.png`

When the local Editor Lockdown pilot is enabled on an eligible Classic Editor
screen, notices remain in context with their original links and controls.
Notifications Center capture continues unchanged elsewhere. This exception
uses the existing editor screen predicate and introduces no provider registry
or persistent configuration.
